Data and Code for GWAS Study

This repository contains the code and data for the manuscript: "GWAS-informed low-density SNP panels and machine learning improve genomic prediction of visceral white-nodules disease resistance in small yellow croaker (Larimichthys polyactis)".

Data Availability

The raw genotype and phenotype data are available at: Zenodo / Figshare Repository.

Code

All custom scripts used in the analysis are provided in this repository.
